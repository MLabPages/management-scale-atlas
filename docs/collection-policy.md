# 尺度と関係の収集・更新方針

学術研究での尺度選定と研究の空白の探索を目的とする。初期範囲は既存の104概念・140尺度。これだけで経営学全域の主要尺度を網羅したとは判定しない。マーケティング・消費者行動、組織行動、戦略・組織能力、技術受容を横断し、候補12件を含む領域別リストを増補する。項目数、原版・短縮版・翻訳版、対象集団、心理測定根拠、日本語の状況、利用条件を別々に確認する。

## 関係の単位

- `association`：概念間の関連。相関や構造モデルは、それだけで因果の証明にはならない。
- `discriminant`：異なる概念・尺度を分けて測れているか。相関が小さいだけで認定しない。
- `convergent`：同じ概念の尺度・版の対応。高い共有分散だけで内容の完全な等価性を認定しない。
- `comparison`：尺度系統の比較。検討結果に限界があれば併記する。
- 関連概念リンク：編集上の調査候補。類似度・因果関係・未検証という事実は推測しない。

原典を両尺度が引用していること、同じ論文で使われたこと、各尺度のαが高いことは、尺度間の関係や弁別・収束妥当性の検証に置き換えない。概念レベルの結果を、登録されている別の具体的尺度版の結果として表示しない。

## 根拠の厚みと研究の空白

画面のM/R/S/?は「登録した根拠の種類・数」を示す。総合的な証拠の質は、独立研究グループ、標本の重複、対象集団、分析水準、尺度版、横断／縦断／実験、バイアス、結果の一貫性、効果量・信頼区間、レビュー方法を確認してから別途判断する。今回は品質スコア・「よく検証された」の自動認定を実装しない。

同じDOIを持つ複数結果を独立論文として数えない。異なる尺度や研究内削除版を用いた論文は、同一尺度ペアの独立追試として数えない。標本の重複・独立性が未集計ならそのまま明示する。

未調査と、範囲を定めて検索したが該当結果を見つけられなかった状態を区別する。後者には検索データベース、検索語、検索日、期間、対象集団、言語、版の採否基準が必要。「未検証」と断言せず「この検索範囲では根拠を確認できず」と表示する。現在の?は未調査であり、空欄は関係未整理である。

## 更新の手順

1. `node collect-literature.mjs --output collection/queue.json`で、未収録候補、使用研究0〜1件、日本語未確認、関係の追加調査キューを作る。
2. 原典・出版社・著者公式資料と、Crossref/OpenAlex等の書誌、Google Scholar、CiNii Research、J-STAGEを使い分ける。現在のスクリプトの検索接続先はCrossrefのみ。Crossrefだけで日本語文献や未検証を判定しない。
3. 接続可能な環境で`--search`を使い書誌候補を保存する。`--since`は索引更新日であり出版日ではない。範囲・検索成功／失敗をログに残す。未完了時は更新日を検証日として進めない。
4. 方法・表・付録で実使用と尺度版、文脈調整・項目削除、分析水準、測定検証または概念間の関係、効果方向、効果量・信頼区間を確認する。反対の結果も同じ基準で収録する。
5. 確認済みの尺度・使用研究を`data.js`に登録し、関係は既存根拠への参照として追加する。根拠の整理日`assembledAt`と原典の確認日を混同しない。
6. `node verify-data.mjs`と、関係画面の検索・出典・出力を確認して変更記録を残す。

定期更新は未設定。今後の運用では月次の文献候補収集、四半期の領域別収録漏れ確認を初期案とし、頻度は運用者が決める。検索の自動実行と、論文内容を確認した登録の更新は別工程とする。
