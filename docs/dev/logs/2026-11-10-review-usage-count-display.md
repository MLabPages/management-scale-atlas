# 「尺度の利用実績」欄の整理

- `usageEvidence`（系統的レビュー内の使用研究数）が登録されているのは200尺度中6尺度（SERVQUAL、BPS、BAS、FSS、ITC-SOPI、IPQ）だけで、残りは詳細・尺度カード・概要に「未集計」と表示されていた。数はレビューの対象範囲内の件数で、尺度間で比較できない。
- 詳細の「尺度の利用実績」欄と、尺度カード・概要・比較表の「利用研究数は未集計」表示を外した。
- 登録がある6尺度は、「この尺度を使った先行研究」欄の先頭に「参考：レビューでの使用数」として、件数・対象研究数・根拠レビュー・リンクを表示する。
- 並び順「利用研究数が多い順」を「使用先行研究が多い順」に改め、個別に登録した使用先行研究の件数で並べる。
- データ（`usageEvidence`）は残した。CSV/JSON出力の該当列も残し、未登録時は空欄になる。
- 作業中に、使わなくなった関数を消す範囲が広すぎて、信頼性・妥当性と実際の研究での使われ方の描画関数まで消えていた。ブラウザ確認で詳細が開かないことを見つけ、HEAD版から2関数を戻した。
- 確認：`node --check app.js`、`node verify-data.mjs`、`git diff --check`。ローカルHTTPサーバーで、カードとBAS・JSSの詳細に「未集計」がないこと、BASに参考行が出てJSSには出ないこと、信頼性・妥当性と実際の研究での使われ方が表示されること、並び替え、コンソールエラーがないことを確認した。
