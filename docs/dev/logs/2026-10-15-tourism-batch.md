# 観光・ホスピタリティ分野の一括追加（v0.97.0）

## 版・日本語・許諾の扱い

- RETS原版の日本語状態は `related-version`、大泉町の11項目適応版は `translated` / `validated` とし、親尺度IDを付けた。正式な汎用短縮版とは表示しない。政治的次元のアクセス・投票表現の変更を注記。
- 日本語は検証済み22、関連版14、未確認106。他の7尺度は今回の検索範囲で日本語検証を確認していない。「日本語版が存在しない」とは断定しない。
- 項目本文は追加しない。利用条件は `unknown`。逆転未確認を「逆転なし」と読まない注記を付けた。
- 開発論文・検証論文を `usageStudies` に加えない。日本語版検証は `japaneseEvidence` と `psychometricEvidence` に記録。
- 関連概念リンクは新規概念内に限る。既存概念や既存の関係レコードは変更しない。

## 今回見送った候補・次回の確認

- Kolar & Zabkar (2010) の真正性：Table 2の投与10項目と最終CFAの2＋3項目を混同しないよう今回未登録。DOI・全文の追加確認後に版の単位を決める。
- SUS-TASの21項目短縮版：原版44と区別し、短縮論文本文を確認してから別レコードを検討。
- MTEの回答形式・原典表、4Eの原典表と回答形式、NS-21の原典本文、RETS-12の原典回答形式、各尺度の独立した使用研究は次回の優先事項。
- 同じURLの検索結果や被引用数を使用研究数へ換算しない。

## 検証

- `node verify-data.mjs`：128概念・173尺度・195使用研究・63ガイド・16関係、整合性検証成功。
- 追加時に既存120概念・164尺度をデータオブジェクト単位で比較し、不変を確認。
- `node --check data.js`、`node --check app.js`、`node verify-data.mjs --self-test`、`git diff --check`：成功。
- Browser plugin not available：Browserスキルがセッションにないため、既存のPlaywright/ChromiumでローカルHTMLを検証。1365×900と390×844。ページ識別・非空表示・エラー表示なし・コンソールエラーなし・画面キャプチャを確認。
- 領域フィルターで9尺度、全9詳細の開閉、概念キーワード検索、原版12項目と日本語11項目の比較、再読込後の選択保持を確認。モバイルで横はみ出しなし。
- JSONは9レコード、CSVは日本語版を含む出力内容を確認。ブラウザの実ファイルダウンロードが環境側でキャンセルされたため、出力ボタンが生成するBlobを捕捉して検証した。OSへのファイル保存成功は未確認。
- 初期確認用の8766番ポートは別アプリが応答したため切り替え、最終検証は同一Nodeプロセス内の動的ポート50127（127.0.0.1）を使用。検証後にブラウザ・サーバーを終了。
- Git開始時はclean、fetch後のorigin/mainとの差分なし。GitHub CLIのPR一覧取得はHTTP 401になったため、認証設定を変更せずCLIの追加呼出しを停止。
