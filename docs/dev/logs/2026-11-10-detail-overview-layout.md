# 尺度詳細の情報提示を見直し

- 採用判断ガイド（回答負担・実使用・測定検証・日本語の4枠と注意文）は、基本情報表と内容が重なり、一目で判断に使いにくかった。ガイドを外し、尺度詳細を次の順に組み替えた。
  1. 原典・文献情報
  2. 尺度の概要：項目数・下位次元数・回答形式・版区分を大きく表示し、下位次元はタグで一覧化。対象者・日本語・利用条件・使用先行研究は補足として下に並べる。従来の基本情報表は廃止した。
  3. 版・派生関係（既存の比較表）
  4. 同じ概念の別候補：この尺度と同じ概念の登録尺度を、版区分・項目数・下位次元・日本語・使用研究件数で並べた比較表。版・派生関係に出る尺度は除き、最大8件を項目数順に表示。比較に追加ボタンつき。
  5. 採用前に確認すること：従来ガイドの注意文を折りたたみ表示で残した。
  6. 確認範囲・使用研究・心理測定・日本語・尺度項目（既存）
- 詳細上部に、概要・版・派生・別候補・使用研究・信頼性・妥当性・日本語・尺度項目への移動ボタンを追加した。スクロール中も上部に固定される。
- データは変更していない。比較表の短い列を折り返さないようにし、スマートフォンでは別候補カードを2列にした。
- 確認：`node --check app.js`、`node verify-data.mjs`、`git diff --check`。ローカルHTTPサーバーで WFCS-18（版・派生関係と別候補あり）と JSS（別候補2件）を、PC幅と390px幅で確認した。移動ボタン、比較追加・解除、コンソールエラーがないこと、スマートフォン幅で横スクロールが出ないことを確認した。
