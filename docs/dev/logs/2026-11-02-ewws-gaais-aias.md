### EWWS

- Crossref。著者 Amy L. Bartels、Suzanne J. Peterson、Christopher S. Reina。PLOS ONE, 14(4), e0215957。DOI `10.1371/journal.pone.0215957`。2019-04-25。CC BY 4.0
- 出版社の本文と Table 1、付録を開いた。8項目。対人4（付録の項目1–4）、個人内4（付録の項目5–8）
- 5件法（1＝strongly disagree、2＝disagree、3＝neither agree nor disagree、4＝agree、5＝strongly agree）
- 検証標本の係数αは全体 .87–.90、個人内 .83–.85、対人 .87–.93
- 探索的因子分析の標本は r = .91（対人）、.86（個人内）、.89（全体）。係数αとは書かれていない
- 2次元の CFI は .96–.99、SRMR は .025–.077、χ² は 39.25–84.24（df = 18）
- 1次元の CFI は .68–.82、SRMR は .11–.16、χ² は 453.41–838.82（df = 20）
- 内容の仕分けは44名。探索的因子分析は南西部の大学のMBA学生120名
- Table 1 は Sample 3 が98、Sample 4 が237、Sample 5 が203、Sample 6 が155、Sample 7 が533
- 考察の1,346名は、Table 1 の5標本と探索的因子分析の120名の合計と一致する。内容の仕分け44名は入らない
- 考察の「7標本」、Table 1 の5標本、平均負荷 .82 の「3標本」は数が一致しない。どちらにも寄せない
- 採点（合計か平均か）の明示はない。尺度の利用許諾の明記はない。付録の項目は転載していない
- 倫理は Arizona State University（IRB STUDY00001649）。同意は免除

### GAAIS と AIAS-21 の使用研究

- Crossref。著者 Qin Zeng、Shenghua Zhang、Jiacheng Hu、Yajun Wu、Min Yang、Yuan Hu。Frontiers in Public Health, 14, article-number 1918134。DOI `10.3389/fpubh.2026.1918134`。2026-07-30。CC BY 4.0
- 出版社ページの本文を開いた。四川省11大学の看護学生。配布1,573、有効1,482（94.2%）。2025年5–10月。SoJump。倫理は 2025–050
- 女性1,324名、男性158名。本文は女性88.5%。Table 1 は89.34%。1,324/1,482 は89.34%と一致する。本文の88.5%は採用しない。平均年齢20.3（SD 1.7）
- GAAIS は20項目。肯定12、否定8。5件法（1＝strongly disagree～5＝strongly agree）。否定を逆転した合計20–100。この標本のαは全体0.954、肯定0.950、否定0.948。平均68.82（SD 16.41）

- 0.957 と 0.958 は引用36（Zeng ら、DOI `10.1186/s12909-026-08685-y`）の参照値
- AIAS-21 は21項目、4次元、7件法、合計。この標本の全体αは0.948。平均76.45（SD 23.31）。論文の理論範囲は21–147。原典の最大136とは一致しない
- 0.880 は引用8の参照値。開発者の Wang, Y.-Y. と Wang, Y.-S.、Schepman と Rodway は著者に含まれない
